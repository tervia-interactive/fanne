Menos abstração.
520MB de controle puro.

O Fanne é uma fundação de sistema operacional desenvolvida pela Tervia Interactive. Sem interfaces gráficas forçadas, sem bloatware em background. Apenas o hardware e as suas decisões.

/boot & Init

CORE

Processo de inicialização estritamente linear. O sistema levanta apenas os daemons definidos pelo usuário no arquivo de configuração base. Nada roda escondido; se está na memória, foi você quem chamou.

Ambiente TTY

INTERFACE

O Fanne não possui servidor de display (X11/Wayland) pré-instalado. Você recebe um console POSIX limpo. Ideal para servidores, sistemas embarcados ou para montar sua própria stack gráfica (Window Manager) do zero.

Gestão de Pacotes

SYS

Gerenciamento de dependências cirúrgico, sem instalar pacotes "recomendados" automaticamente. O repositório oficial da Tervia garante binários otimizados que respeitam o limite de footprint da base.

Anatomia do Sistema

Tamanho Padrão (ISO/Instalação)
Exatos 520 MB (Pode variar ligeiramente dependendo do particionamento de swap e firmware de rede incluso).
Coreutils & Userland
Implementação enxuta, fornecendo as ferramentas GNU essenciais (ls, grep, awk, sed) para administração do sistema sem duplicidade de binários.
Sistemas de Arquivos
Suporte nativo a ext4 (padrão) e ferramentas básicas para montagem de partições FAT32/vfat no boot (EFI).
