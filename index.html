O essencial.

O Fanne é um sistema operacional base focado no estritamente necessário. Projetado pela Tervia Interactive para ser uma fundação enxuta, estável e livre de bloatware.

Filosofia do Sistema

Sistemas operacionais modernos frequentemente entregam gigabytes de serviços e interfaces gráficas que o usuário nunca solicitou. O Fanne segue o caminho oposto.

Entregamos uma infraestrutura mínima de funcionamento. A partir da base instalada, a decisão do que deve rodar, qual interface usar (ou se haverá uma) e quais serviços iniciar é inteiramente do administrador.

Status de Desenvolvimento

O Fanne encontra-se em desenvolvimento ativo pela Tervia Interactive em 2026. A infraestrutura de pacotes e o sistema de inicialização estão sendo otimizados para garantir que a pegada inicial no disco permaneça no limite estrito arquitetado.

Nota: A documentação oficial da API do sistema e o manual do usuário estão sendo redigidos e serão publicados no repositório assim que a build principal atingir maturidade estável.
